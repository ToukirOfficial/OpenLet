# OpenLet

Free, open-source property and tenancy management for small landlords and small letting agents: properties, tenants, rent tracking, repairs, documents and certificates in one place, with a portal for tenants.

Self-hosted: install it on your own server, keep your own data, pay nothing.

🚧 In development. See [FEATURES.md](FEATURES.md) for what it will do and [PRD.md](PRD.md) for the full product brief.
