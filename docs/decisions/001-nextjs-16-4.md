# 001: Next.js 16.4 instead of 16.3

**Date:** 2 November 2026

the project rules pins Next.js 16.3.x. Every 16.3 release, including the last one (16.3.8), has two critical advisories (unauthenticated remote code execution in the image optimiser and in `use cache` functions) and one high (denial of service through Server Actions). They are fixed only in 16.4.1 and later.

With the owner's approval, OpenLet uses **Next.js 16.4.4**, the latest stable release (not canary).
